## How to run locally

### Prerequisites

Before running the project locally, make sure you have:

- PNPM
- Node.js
- Git

First of all, clone the project with SSH or HTTPS using Git:

```bash
git clone https://github.com/OscarDevv/wired-os.git # With HTTPS
git clone git@github.com:OscarDevv/wired-os.git # With SSH
```

After you have the project in your machine, install all dependencies, note that this project is made using PNPM, so others packages managers are not officially supported:

```bash
pnpm install
```

Then run the project and open `localhost:5173`:

```bash
pnpm dev
```

After that, you can do whatever you want with the project in your machine, and also, go and check both `package.json` files to view all scripts:

- [Root package.json](https://github.com/OscarDevv/wired-os/blob/main/package.json)
- [Front-End package.json](https://github.com/OscarDevv/wired-os/blob/main/frontend/package.json)
